- The canonical optimization playbook is [KNOWLEDGE_CORE.md](./KNOWLEDGE_CORE.md).

- The binding rule is localization before editing: a cause is a named number at a named node. A confident diagnosis whose numeric prediction does not match the observed symptom to within an order of magnitude is a hypothesis, not a cause.
- Falsified hypotheses are deliverables, not embarrassments. More die than survive here, and the dead ones are what stop the next investigation repeating this one.
- Measure the interval a player waits, report the maximum alongside the percentiles, run it twice, and report both runs.
