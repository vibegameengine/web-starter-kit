# The prompts, as sent

**These are reconstructed, not logged.** The run they come from was executed by a
single agent playing all the parts in sequence — it could not fan out — so no
literal prompt transcript exists. Each file here is rebuilt faithfully from the
critique it produced: the lens, the exclusions, the paths, the frame, the
measurement commands and the output contract are all exactly what that critique
was written against, and every critic below is answered somewhere in
[`../critique/round-1.md`](../critique/round-1.md). The wording of the
instructions is a reconstruction.

They are still worth having in this form, because the labour the process
actually demands of you is authoring five of these, and nothing else in the repo
shows you what one looks like when it is finished rather than when it is
described.

taken out. If you are starting a run, fill in the templates; if you are trying to
work out how specific "specific" has to be, read these.
